Help & FAQ

How do I get verified? +

Register with your @mmarau.ac.ke email. You are auto-verified. Others can be manually verified by admin.

Why is my listing PENDING? +

Unverified sellers go to admin review. Verified sellers publish instantly. Admin approves/rejects in /admin → Moderation.

How do boosts work? +

Click ⚡ Boost, pay via M-Pesa STK. Transaction stays PENDING until Daraja callback confirms. Then listing is Featured for 7 days (configurable).

How do I report a scam? +

Open any listing → Report → choose SCAM/FAKE/INAPPROPRIATE. Admin sees it in safety queue and can takedown + suspend.

Exact deploy steps (owner checklist)
  1. Download ZIP → unzip → git init, add, commit, push using script above.
  2. Create Neon Postgres → copy DATABASE_URL (pooled + direct).
  3. Create Cloudinary account → copy cloud name, API key/secret + upload preset.
  4. Create Daraja app (Safaricom Developer) → consumer key/secret, shortcode, passkey, callback URL.
  5. In Vercel → New Project → import repo → add all env vars from .env.example.
  6. Deploy → run npx prisma migrate deploy && npx prisma db seed (or via Vercel build).
  7. Login at /login with ADMIN_INIT_EMAIL → verify /admin loads, others get 403.
  8. Test: register student, post product/house/service, upload images, search, boost (sandbox), report, moderate.
