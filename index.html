Safety Guide

1. Meet on campus, in public.
Best spots: Library Square, Student Centre, Campus Gate cafeteria — daytime only. Never go to someone's room alone for a first meet.
2. Inspect before you pay.
Test electronics, try shoes, check M-Pesa phone IMEI (*#06#). For rooms, view in person with a friend.
3. Pay with M-Pesa, in person.
Never send deposits in advance. Mara Market will NEVER ask for your M-Pesa PIN.
Red flags: prices too good to be true, seller refuses campus meet-up, asks for delivery fee upfront, non-MMU email.

Disclaimer: Mara Market connects students but does not handle payments or deliveries. All transactions are at your own risk — stay alert, comrade.

Developer Setup · Next.js + Supabase

This interactive MVP runs fully in one file using LocalStorage as the database layer (tables: users, products, categories, images, favorites, seller_profiles, messages, reports). To ship production:

npx create-next-app@latest mara-market --tailwind cd mara-market && npm i @supabase/supabase-js # .env.local NEXT_PUBLIC_SUPABASE_URL=... NEXT_PUBLIC_SUPABASE_ANON_KEY=... npm run dev # → http://localhost:3000
-- PostgreSQL / Supabase schema create table users(id uuid primary key default gen_random_uuid(), name text, email text unique, phone text, hostel text, avatar text, verified bool default false, role text default 'student', created_at timestamptz default now()); create table categories(id text primary key, name text, icon text, color text); create table seller_profiles(id uuid primary key, user_id uuid references users(id), shop_name text, bio text, cover text, rating numeric default 5, followers int default 0); create table products(id text primary key, seller_id uuid references users(id), title text, price int, category text references categories(id), condition text, description text, location text, negotiable bool, sold bool default false, featured bool default false, views int default 0, created_at timestamptz default now()); create table images(id uuid primary key default gen_random_uuid(), product_id text references products(id) on delete cascade, url text, pos int); create table favorites(user_id uuid references users(id), product_id text references products(id), primary key(user_id, product_id)); create table messages(id uuid primary key default gen_random_uuid(), from_id uuid, to_id uuid, product_id text, body text, created_at timestamptz default now()); create table reports(id uuid primary key default gen_random_uuid(), product_id text, reporter_id uuid, reason text, note text, status text default 'open', created_at timestamptz default now()); -- Storage: bucket `listing-images` (public). RLS: students read all; insert own; admin full.
